## Sobre o Projeto

Este repositório contém a página centralizadora de links (estilo *Linktree*) para o projeto **Apotecário RPG**. O objetivo é reunir em um só lugar as redes sociais, fichas de RPG, guias de poções e materiais do sistema.

---

## Tecnologias Utilizadas

- **HTML5**: Estruturação dos links e componentes.
- **CSS3**: Estilização visual, cores e layout responsivo.
